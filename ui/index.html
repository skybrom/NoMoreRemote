Stream Deck launchers

Each launcher is a small app that runs one function on your Nova. Drag it from Finder onto a Stream Deck key (Stream Deck makes an Open action from it). Hover a tile and click + Deck to make just that one.

Power Off and Reboot launchers always ask first. Network entries have none. The launchers use a copy of the command line kept in your Library folder, so they keep working if you move this app.

MIDI

Any controller, or a Stream Deck MIDI plugin, can run every function. Send MIDI to the port Trinnov Functions (it appears in MIDI apps by itself), or from any controller already connected to this Mac. A button press is a note on, a program change, or a CC at 64 or more.

To map one function: hover its tile, click MIDI, then press the key on your controller. Power Off and Reboot cannot be mapped (a stray note would switch your Nova off).
